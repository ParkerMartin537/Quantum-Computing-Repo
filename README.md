Verification Confirmation
The instructions below can be used to verify the quantum computing documents against my GPG key to ensure that everyone knows who the original creator is and to make sure no mimicking documents are created.
1. gpg --import public-key.asc — This command allows you to import the public key on your device. You can run this command in PowerShell or the command terminal.
2. gpg --verify "Quantum Encryption Model.pdf.asc" "Quantum Encryption Model.pdf" — This command allows you to verify the signature using the public key specifically for the Quantum Encryption Model. Make sure to adapt the file path to where the files are located on your device.
